## Implemented but deliberately disabled / not implemented

Telemetry v1 publisher, sensor drivers, draft config parser, ESP32 NVS adapter, draft display parser and pure decisions are implemented. Runtime network/pin access/draft flags default disabled. Draft ACK generator is Serial-only and uses `acknowledged`; generic report generator emits nulls, never inferred ON. There is no authenticated session network implementation, ACK/report network sender, physical actuator driver, manual command endpoint, real calibration, real push or backend deployment in this phase. These omissions follow explicit safety and backend constraints, not a claim that those services are already live.

Transport caveats needing device verification: IP SAN trust anchors, SNTP reliability/drift/holdover, bounded blocking API timing, ESP8266 TLS heap/fragmentation, watchdog under I2C faults, ADC disconnected-wire detection and library/model compatibility with actual modules. Pin labels, example values and compilation are not physical approval.
